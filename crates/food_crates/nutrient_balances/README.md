# Nutrient balances
Crate for calculating nutrient balances

## Defaults
* % Omega-6 (LA)
* Omega-6 to Omega-3 (omega 6 (g) / omega 3 (g))
* Zinc to Copper - zinc (mg) / copper (mg) - between 8 : 1 and 15 : 1, target 10 : 1
* Potassium to Sodium
* Calcium to Magnesium (Calcium (mg) / Magnesium (mg)) - between 1.7 : 1 and 2.6 : 1, target 2 : 1 - DOI number: 10.1093/advances/nmaa160
* Calcium to Oxalate

* Pral Alkalinity?

Allow customs - % based or Ratio of different nutrients
Have customisable explanation text
