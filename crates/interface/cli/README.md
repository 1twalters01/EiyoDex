# CLI
Manage CLI functionality

## Profile
eiyodex profile new
eiyodex profile <profileName>
eiyodex profile <profileName> delete

## Read data
eiyodex help
eiyodex version
eiyodex view
eiyodex view <date>

## Update data
eiyodex add <item> <quantity><units>
eiyodex add <item> <quantity><units> to <mealCategory>
eiyodex add <item> <quantity><units> at <time>
eiyodex subtract <item> <quantity><units>
eiyodex subtract <item> <quantity><units> from <mealCategory>
eiyodex delete <item>
eiyodex delete <item> from <mealCategory>
eiyodex delete entry
